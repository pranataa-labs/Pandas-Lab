Repositori modul dan latihan interaktif komprehensif (75 topik) untuk menguasai pengolahan data, rekayasa fitur, analisis statistik, time series, dan optimasi performa menggunakan **Pandas** di Google Colab atau JupyterLab.

---

## 📌 Topik Pembelajaran

- **Struktur Data Dasar**: Import Pandas, Pandas Series, DataFrame, Membaca CSV, Inspeksi Data, Info & Shape, Statistik Deskriptif
- **Seleksi & Indeksasi**: Memilih Kolom, Slicing Baris, Seleksi `.loc` & `.iloc`, Boolean Indexing, Filter Multi-Kondisi, Filter `.isin()`, Manipulasi Indeks
- **Pembersihan Data (Cleaning)**: Deteksi Missing Values, Menghapus Missing Values, Mengisi Missing Values, Deteksi & Hapus Duplikasi, Ubah Tipe Data, Ganti Nilai, Hapus Kolom/Baris, Ganti Nama Kolom
- **Manipulasi & Transformasi**: Kolom Baru, Fungsi `.apply()`, Mapping `.map()`, Mengurutkan Data, Nilai Unik, Frekuensi Nilai, Manipulasi Teks `.str`, GroupBy, Agregasi Data, Cross Tabulation, Pivot Table
- **Penggabungan Data**: `pd.concat()`, `pd.merge()`, `.join()`, Konversi Datetime, Ekstraksi Waktu, Resampling Time Series
- **Visualisasi & Ekspor**: Line Plot, Bar Plot, Histogram, Box Plot, Scatter Plot, Membaca JSON & HTML, Ekspor CSV & Excel, Kustomisasi Tampilan, Optimasi Memori
- **Analisis Lanjutan & Rekayasa Data**: Shifting & Lagging (`.shift`, `.diff`, `.pct_change`), Rolling Windows & Moving Average, Expanding Windows, GroupBy Transform & Filter, Hierarchical Indexing (`MultiIndex`), Cross-Section (`.xs`), Stack & Unstack, Reshaping Melt, Explode List Bersarang, Ekstraksi String Regex (`.str.extract`, `.str.contains`), Categorical Data & Ordered Categories, Binning (`pd.cut`, `pd.qcut`), Deteksi Outlier Metode IQR, Method Chaining (`.pipe`), `.combine_first()`, Ranking Data (`.rank`), Matriks Korelasi & Kovarians, Integrasi Database SQLite, Chunksize I/O untuk Data Besar, Format Mata Uang/Persentase, Timezone & PeriodIndex.
