## 📌 Curriculum & Core Learning Modules

- **Core Data Structures:** Pandas initialization, Series construction, DataFrame creation, CSV ingestion, data inspection, structural auditing (`info`, `shape`), and descriptive statistics (`describe`).
- **Selection, Slicing & Indexing:** Column projection, row slicing, label & positional lookups (`.loc` & `.iloc`), boolean masking, multi-condition filtering, membership validation (`.isin()`), and index mutations.
- **Data Quality & Cleaning:** Missing value detection, dropped rows/columns, imputation strategies, duplicate auditing, type casting, value replacement, structural column pruning, and semantic renaming.
- **Transformations & Feature Engineering:** Calculated columns, row-level `.apply()`, dictionary mapping (`.map()`), sorting, unique value counts, value frequency tables, vectorized string operations (`.str`), grouping operations (`groupby`), multidimensional aggregation, cross-tabulation, and pivot tables.
- **Merging & Time Series Analysis:** Concatenation (`pd.concat()`), relational joins (`pd.merge()`, `.join()`), datetime parsing, temporal component extraction, and time-series resampling.
- **Visualization, I/O & Memory:** Line, bar, histogram, box, and scatter visualizations, JSON & HTML parsing, CSV/Excel persistence, display customization, and categorical memory optimization.
- **Advanced Analytics & Data Engineering:** Temporal shifts & lags (`.shift`, `.diff`, `.pct_change`), rolling windows & moving averages, expanding windows, grouped transformations, hierarchical indices (`MultiIndex`), cross-section lookups (`.xs`), stacking & unstacking, wide-to-long melting, nested list explosion, regex string extraction (`.str.extract`, `.str.contains`), ordered categorical types, continuous binning (`pd.cut`, `pd.qcut`), IQR outlier detection, method chaining pipelines (`.pipe`), non-destructive coalescing (`.combine_first()`), competitive ranking (`.rank`), correlation & covariance matrices, SQLite database engine integration, chunked I/O streams for large datasets, currency & percentage formatting, and timezone-aware arithmetic.
